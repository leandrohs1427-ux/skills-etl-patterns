# Skills de conhecimento

Biblioteca de skills para uso com assistentes de IA (Claude e outros).
Cada skill fica em uma pasta dentro de `skills/` e tem um `SKILL.md` como arquivo principal.

## Skills disponíveis

| Skill | O que faz |
|-------|-----------|
| [etl-patterns](skills/etl-patterns) | Catálogo e guia de decisão de 10 padrões de ETL, com exemplos em Databricks |

## Estrutura de cada skill

```
nome-da-skill/
├── SKILL.md        (instruções principais e guia de decisão)
└── references/     (material de apoio, lido sob demanda)
```
